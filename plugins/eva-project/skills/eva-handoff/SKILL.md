# 写出 Eva 交接

使用 Eva MCP，项目取自用户明确指定或 `AGENTS.md` 的 `Eva identifier`。若有多个实例或身份，先用 `eva_connection_info` 核对。工作线沿用需求编号或已有稳定标签。

先查 `handoff_latest`。本会话已有交接需要补充时原地更新章节和待办；新会话承接已领取交接后写出下一份时引用 previous。需要替代未领取交接时先核对它的实际状态，按工具合同处理 supersede。

保存前核对仓库路径、分支、完整 HEAD、工作区改动、实际服务环境、验证结果和仍有效的用户授权。`handoff_save` 保存背景、主线、现状、待办、注意事项、仓库/基线和真实来源会话。

待办每项使用稳定标识，关联实际需求编号；勾选仅表示执行步骤完成。待办中的状态以需求池最新状态为依据。写清下一步可操作的内容、阻塞及归属，保留未知事实为未知。

正文应能由不同 Agent 接手，描述实际工作与环境。工具参数和客户端安装说明留在插件文档中。

写后回读摘要，报告交接编号、待办进度和 Eva 链接。只有用户要求新会话或指定接手者时，才使用宿主可用的会话能力派发；没有该能力就提供交接编号。
