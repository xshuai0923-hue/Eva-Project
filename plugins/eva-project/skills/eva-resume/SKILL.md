# 接手 Eva 工作线

使用 Eva MCP；项目来自用户指定或 `AGENTS.md` 中的 `Eva identifier`。核对连接身份后，已知工作线先用 `handoff_latest` 取摘要，已知编号用 `handoff_get`。按需要读取背景、主线、现状、待办和注意事项。

核对真实仓库与基线。Git 项目使用 `git merge-base --is-ancestor <baseCommit> HEAD` 判断基线是否包含在当前历史中。分支名变化单独说明；仓库不符或基线不在当前历史时先澄清，避免在错误代码上继续。已有未提交改动要明确归属。

用户仅移交上下文时读取后等待；用户授权继续时，以真实 Agent 和会话标识调用 `handoff_claim`。有领取冲突则报告，不抢占活跃会话。

读取关联需求的最新范围、状态与授权，再做未完成待办。交接与需求状态不一致时，以需求记录为准，按授权修正过时记录。完成步骤更新待办；完成需求仍要提交真实证据及适用验收。

需要继续移交时保存新的交接并关联前一份。领取、登记和交接不增加部署、删除或对外发送权限。
