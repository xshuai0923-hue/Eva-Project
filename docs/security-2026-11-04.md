## 运行行为

- 每个 HTTP 请求新建一个 `McpServer` 和一个无状态传输对象，不再跨客户端共享响应路由。请求完成或客户端断开时释放对象，停机时关闭仍活跃的传输。
- HTTP 请求体最多 32 MiB，超限返回 413，涵盖 Content-Length 声明和分块传输。该限额容纳现有 20 MiB 二进制附件的 Base64 表示和 JSON 包装；附件本身仍由业务层限制为 20 MiB。
- 单次工具调用的数组元素和对象成员总数最多 10,000，在进入工具业务处理前检查。
- 使用修复后 SDK 的批次数量上限（100 条），拒绝超长批次。
- 仍先通过 Eva 自己的 Token 存储认证，再进入 SDK；不切换到 SDK 的 OAuth/Bearer 中间件。网页接口现有的 16 KiB 请求体限制保持独立。

## 验证与更新

`src/mcp-http.test.ts` 通过真实 HTTP 传输验证：多个用户用相同 RPC ID 并发请求时身份和响应互不串线、初始化后继续调用、输入元素超限拒绝、超长批次拒绝、声明及分块请求体超限拒绝、20 MiB 附件兼容、断开连接释放资源，以及认证发生在 MCP 对象创建之前。

运行 `npm run typecheck`、`npm test`、`npm run build`、`npm audit --omit=dev`，并执行网页和插件测试。更新运行实例需要构建 MCP 镜像并重建 MCP 容器；无需重建字段、重跑 bootstrap、修改数据库或轮换用户 Token。更新前保留旧 MCP 镜像及私有配置备份，更新后核对运行依赖审计、并发身份隔离、网页和 MCP 健康及已安装插件的协议兼容性。备份和部署回执保存在私有运行目录，不进入 Git。

本次验证：403 项 MCP 测试、122 项网页测试和 10 项插件测试通过。`deploy/dev/smoke-mcp-security.mjs` 在候选容器中使用仅保存在容器临时文件中的两个测试身份，以相同 RPC ID 并发调用 40 次；身份隔离及三类超限拒绝均通过，未创建真实网页账号或修改真实 Token。上线后使用实例现有身份复核相同 RPC ID 并发、超限拒绝、服务健康和插件只读连接。若实例仅有一个启用身份，线上检查不声称验证了跨用户隔离，该项以双身份候选容器和延迟响应回归测试为依据。
