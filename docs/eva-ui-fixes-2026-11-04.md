## 附带修正

网页 JSON 请求原统一限制为 16 KiB。为使新的附件上传与长文本编辑实际可用，业务文本路径调整为 1 MiB，附件上传路径为 32 MiB（覆盖 20 MiB 文件的 Base64 扩张）；普通管理和配对请求保留原有 16 KiB 限制。文件内容、类型和大小仍由附件服务再次检查。

编辑失败保留表单；版本冲突不自动取新版本覆盖。服务端操作能力是界面提示，所有更新仍重新检查权限与记录版本。
